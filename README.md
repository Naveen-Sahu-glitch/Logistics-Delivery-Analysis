
# Logistics Delivery Performance and Delay Analysis

## Project Overview
This project analyses historical e-commerce delivery data using Python to understand delivery performance and late deliveries.

## Objectives
- Calculate on-time and late delivery rates.
- Measure average delivery time.
- Calculate average delay among late orders.
- Analyse monthly delivery performance.
- Support data-driven logistics decisions.

## Dataset
Brazilian E-Commerce Public Dataset by Olist.

Dataset link:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The dataset contains historical Brazilian e-commerce data.

## Technologies
- Python
- Pandas
- GitHub

## Key Performance Indicators
1. On-time delivery rate
2. Late delivery rate
3. Average delivery time
4. Average delay among late orders
5. Average freight cost per eligible order

## Methodology
1. Collect the public dataset.
2. Inspect and clean the data.
3. Convert date columns.
4. Calculate delivery KPIs.
5. Analyse delivery patterns.
6. Interpret the results.

## How to Run
Install the required library:

pip install pandas

Download the dataset and place
olist_orders_dataset.csv inside the data folder.

Run the Python script:

python logistics_analysis.py

## Expected Outputs
- Delivery KPI report
- Delivery-time analysis
- Data-driven recommendations

## Limitations
This is historical data from Brazil, not live Indian logistics data.
Conclusions will be based on the actual analysis results.
